## 📌 About The Project

**Hari Ash Natural Organics** is a modern, responsive web application designed for fresh, hygienic, and ready-to-cook agricultural supplies. We specialize in daily peeled garlic, organic pastes, pre-cut vegetable packs, and bulk supplies for restaurants, catering services, cloud kitchens, and households.

---

## ✨ Key Features

- 🛒 **Interactive Shopping Cart:** Real-time quantity updates, weight variant selection (250g, 500g, 1kg, 5kg+), and dynamic bill calculation.
- 📲 **1-Click WhatsApp Ordering:** Direct order dispatch through WhatsApp with pre-filled cart details and buyer delivery info.
- 🧄 **Specialized Product Catalog:**
  - **Fresh Peeled Garlic:** Machine & hand-sorted, clean, hygienic, ready-to-use cloves.
  - **Pure Garlic & Ginger Paste:** 100% natural, preservative-free freshly ground paste.
  - **Cut Vegetable Packs:** Pre-cut, ready-to-cook vegetable assortments for quick meals.
  - **Bulk Commercial Supply:** 5kg to 25kg+ bulk bags for hotels, dhabas, and caterers at wholesale rates.
- 🔍 **Live Search & Category Filters:** Quickly search items by name or filter by categories.
- 📱 **100% Mobile Responsive:** Optimized touch controls, smooth scrolling, floating cart summary drawer, and fast load times.
- 🎨 **Modern Aesthetics:** Built with Tailwind CSS, micro-interactions, smooth entrance animations, and clean typography.

## 🚀 Getting Started

Follow these steps to run the project locally on your machine:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/puneetkumawat689-lang/HariAsh.git
   cd HariAsh
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
